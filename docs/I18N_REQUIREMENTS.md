# 中英文支持 — 当前 Goal 的范围追加

日期：2026-11-14。状态：已纳入原 Goal 并完成实现与验收，J36–J40 均通过；证据见验收记录与视觉报告。此文件补充 `GOAL_EXECUTION_SPEC.md` 和 Handoff；继续沿用原 Goal、M1–M4 和参考 UI。实际进度见 `docs/handoff-progress.md`，不能将需求说明视为完成证据。

## 1. 用户体验

- 支持简体中文 `zh-CN` 与英文 `en-US`，顶部提供「中文 / English」语言切换入口，沿用现有工具栏样式。
- 初始语言按「已保存的用户选择 → 浏览器语言 → 简体中文」确定；浏览器英文使用英文，中文或其他未支持语言回退简体中文。选择保存在本地，刷新后保留；设置文档的正确 `lang`。
- 覆盖 Playground、Plugins、API & Docs、Benchmarks，包括组件分类、模板、字段说明、按钮、提示、空态、状态、错误摘要、弹窗、复制入口、调试器及无障碍名称。
- 切换语言即时更新平台文案，不刷新整个页面，不重新开始播放，不清除已编辑的表单/JSON、当前 Surface、用户输入/焦点、Action 历史或会话。
- Preview Host 的平台文案与工作台同步；两个示例插件的固定文案也支持两种语言。Native 与 Sandbox 行为一致。

## 2. 内容边界

- 翻译平台拥有的文案及两个示例插件的固定文案。组件类型名、插件 ID、版本、API 路径、JSON Key、Action 名、代码和协议标识保留原样。
- Agent 返回内容、上传 JSON/JSONL、手工编辑的数据、用户输入与第三方插件自己的业务文案不做自动翻译或改写。
- 内置示例可提供两种语言的初始文案；语言切换不能覆盖已载入或已修改的示例业务数据。只有显式恢复/重新载入示例时，才应用当前语言的示例初始值。
- 第三方插件可读取宿主 locale 并自行提供翻译；未提供译文时显示其原始内容，不阻止安装或渲染。开发指南说明这个边界。
- UI 内置接入说明、Agent Quickstart、API Reference 和 Plugin Developer Guide 提供两种语言；README 提供两种语言的入门入口。内部 PRD、执行日志和验收记录可继续使用中文。
- API 的机器可读错误 `code`、参数、JSON Pointer 与原始协议内容保持稳定。UI 翻译可读摘要；第三方/官方 SDK 的原始诊断保留在详情中，不假装全部来自平台词典。

## 3. 实现约束

- 使用类型约束的词典和统一翻译入口；中英文 key 必须一致，支持变量插值与必要复数。禁止逐个页面散落语言判断或运行时机器翻译。
- 日期、数字、货币在平台展示层使用 `Intl` 并显式传入 locale；不改写 wire 数据、原始代码、导出数据或基准测试数值精度。API 时间戳继续使用 ISO 8601。
- 平台运行配置增加 `locale`；可选的 API `preview.locale` 仅接受 `zh-CN` / `en-US`，未提供时默认 `zh-CN`，会话查询返回最终值。
- locale 属于平台配置，不新增 A2UI Wire 命令、不注入业务 DataModel。工作台 → Preview Host → Sandbox 通过现有受校验的配置通道同步 locale。
- 本项目 Plugin SDK 增加 `useHostLocale()`，两个运行模式使用同一接口；切换 locale 更新已有实例，不因语言切换而卸载/重新挂载插件。接口及默认值写入插件指南。
- 上传插件的发现元数据保留原始名称/说明；平台自己的字段说明支持双语。第三方插件的本地化元数据扩展不作为本次必须实现的额外协议。
- 清除代码中目前写死的中文平台文案；新增文案一并进入词典。保留官方 SDK 与上传代码的隔离边界。

## 4. 与视觉还原的关系

- 中文模式继续对照 ZIP 内 v2 原型，固定 `zh-CN` 和原有示例数据，不修改参考文件。
- 语言切换入口属于已授权新增入口；英文文案由中文语义等价翻译，不另做页面设计。
- 英文保留相同布局、Token、图标与交互；允许必要的按钮宽度、局部换行和窄屏排布调整，不能遮挡操作、造成文字裁切或横向溢出。
- 1440×900、1280×800、375×812 均检查中英文；覆盖浅色/深色及核心弹窗。中文保存参考/实现/差异图；英文保存实现截图和布局检查记录，无需虚构英文参考截图。
- 视觉报告注明英文没有原始参考图，以及新增语言入口和文案长度带来的允许差异。
